# FREDKA CONSULT

Single-page website for FREDKA CONSULT, a healthcare management and HR services firm.

**Live demo:** https://yooku98.github.io/Fredka-consult/

## What's on the page

- Hero introducing the firm
- Core services: healthcare staffing, healthcare management, general staffing, training & development, HR advisory
- About section and trusted-clients strip
- Contact call-to-action (email)

## Stack

Plain HTML and CSS in a single `index.html` (Google Fonts: Poppins, Merriweather). No build step and no JavaScript.

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

## Deployment

Served by GitHub Pages from the root of `main`.
